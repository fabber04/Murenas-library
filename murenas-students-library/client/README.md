# Murena's Students Library

This project is a web application for managing student library resources. It consists of a client-side React application and a server-side Node.js application.

## Client Setup

The client is built using React and provides a user-friendly interface for interacting with the library system.

### Installation

1. Navigate to the client directory:
   ```
   cd client
   ```

2. Install the dependencies:
   ```
   npm install
   ```

### Running the Client

To start the client application, run:
```
npm start
```
This will launch the application in your default web browser.

### Project Structure

- **src/**: Contains the source code for the React application.
  - **index.jsx**: Entry point of the application.
  - **App.jsx**: Main application component with routing.
  - **App.css**: Styles for the application.
  - **components/**: Contains reusable components like the Header.
  - **pages/**: Contains page components such as Home, AdminDashboard, and NotFound.
  - **routes/**: Contains route definitions for the application.
  - **services/**: Contains API service functions for server communication.

### Features

- User authentication and authorization for admin access.
- Admin dashboard for managing library resources.
- Responsive design for optimal viewing on various devices.
