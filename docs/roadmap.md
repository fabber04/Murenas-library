Roadmap & Milestones
====================

Phase 0 — Planning (done)
-------------------------
- Requirements, data model, API, IA, roles & permissions

Phase 1 — Scaffold & Foundations (Week 1)
-----------------------------------------
- Pick stack and scaffold app + repo
- Auth (admin + optional student registration)
- DB schema migration
- File storage integration (S3-compatible) and virus scanning

Phase 2 — Public Pages (Week 2)
-------------------------------
- Home, Academics (calendar, exams, notices, SRC)
- Information (enquiry, updates, venues)
- Sports (venues, contacts, competition dates)

Phase 3 — Materials & Search (Week 3)
-------------------------------------
- Materials listing, filters, detail, downloads
- Admin upload flow
- Student submission form + moderation queue

Phase 4 — Security Reports (Week 4)
-----------------------------------
- Report form with attachment
- Admin inbox: triage, assign, resolve, audit log

Phase 5 — Polish & Launch (Week 5)
----------------------------------
- Accessibility pass, performance tuning, error monitoring, backups
- Docs and handover

KPIs
----
- p95 API latency ≤200ms, page LCP ≤2.5s
- Time-to-approval for submissions ≤48h
- Zero critical security findings
