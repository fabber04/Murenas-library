Contributing Guide
==================

Getting Started
---------------
- Fork and clone the repository.
- Create a feature branch from `main`.
- Write clear commits and open a PR when ready.

Coding Conventions
------------------
- Prefer explicit, descriptive names; avoid abbreviations.
- Add meaningful comments only where non-obvious.
- Keep functions small with early returns; avoid deep nesting.
- Write accessible UI (labels, keyboard nav, contrast).

Git & Reviews
-------------
- Conventional commits style (feat, fix, docs, chore, refactor).
- Small PRs with description, screenshots for UI.
- All admin-affecting changes require at least one review.

Security & Data
---------------
- Never commit secrets.
- Validate uploads; respect size/type limits.
- Follow least privilege for roles/permissions.

Issue Labels
------------
- `good first issue`, `bug`, `feature`, `documentation`, `security`, `help wanted`.
